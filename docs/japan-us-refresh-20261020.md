# 日本站样式迁移与代码检查记录

本次以美国站 `a6339af032163a1ad4554d523831cbf0b670308c` 为参考，在日本站 `f1250099c890261100aee2d893cbbc6e2185df09` 基础上完成修改。分支为 `codex/jp-us-refresh-20261020`。本记录仅描述合并前的本地修改与验证，线上发布结果另行核对。

## 界面变化

- 移植 54 种图标微动效、导航滑动反馈、手机玻璃导航、开关拖拽，以及「更多」面板下滑、回弹和中途重新拖动。
- 主题从设置按钮中心扩散，支持快速连续选择、焦点归还、系统主题及减少动态效果偏好。
- 取消整页入场位移，底部留白按导航实际高度计算。
- 保留日股页面、东京时段、默认红涨绿跌、日中英文字与日本专属业务。美国站源码没有改动。

具体交互与来源许可见 `UI_DESIGN_SYSTEM.md` 和根目录 `THIRD_PARTY_NOTICES.md`。

## 缺陷修复

| 问题 | 修改 |
| --- | --- |
| 响应头到达后超时保护失效，正文可能一直等待 | 复用美国站正文下载的总时限、取消及大小限制 |
| `Headers` 或键值数组形式的请求头丢失 | 使用标准请求头对象合并，保留写入保护头 |
| 非 JSON 错误丢失重试时间 | 读取响应头，兼容秒数及 HTTP 日期 |
| 延迟返回的 304 读取了刷新后另一份数据 | 固定条件请求发起时对应的数据，旧响应不回写缓存 |
| 手动刷新仍在有效期内读到旧缓存 | 首页、市场、决算、数据状态的相关刷新先清缓存，再强制读取 |
| 搜索词清空后旧搜索结果重新出现 | 输入变化和组件卸载时使旧请求失效 |
| 收藏星标失败没有反馈 | 显示已有错误提示，避免未处理的拒绝 |
| 普通账号与所有者权限同时存在时，切换账号不清旧数据 | 统一数据身份，客户会话优先；同步清缓存、页面和自选查询 |
| 财报三个接口始终使用所有者自选 | 按当前客户、所有者或匿名身份提供关注标记 |
| 数据目录含 `?/#/%` 等字符时只读连接解析错误 | 使用标准文件网址转换，保留只读约束 |
| 数据库查询异常被当作“尚未发布” | 删除无依据的吞错，保留真正无记录时的空值 |

## 清理与优化

确认源码、测试、脚本及文档引用后，删除只写不读的持久缓存、无调用的恢复接口、旧模拟接口封装、旧创建任务封装、独立语言与颜色切换组件、移动端判断钩子、`hasFacts` 及旧过渡辅助函数。内存缓存、并发请求合并、条件请求与身份切换失效机制继续保留。

后台标签页停止时钟重绘，返回前台时立即校时。新动效模块仅保留实际使用的弹簧和手势，移除了磁力井、通用参数解析及演示接口；9 组回弹轨迹的全部关键帧、时长和动画选项在清理前后逐字节相同。

保留外部数据解析、网络异常、浏览器存储及操作取消等有实际用途的防护。美国站模型任务、模型冷却和美国数据结构专属优化没有迁入日本站。
