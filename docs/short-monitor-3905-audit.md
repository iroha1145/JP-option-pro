## 2. 合計をどう数えたか

24 の保有者の最新値を単純合計すると **9.62%**。実際に合計しているのは
**1.23%（1 社）**。

| 区分 | 社数 | 合計に入れるか | 理由 |
| --- | --- | --- | --- |
| 報告義務中・直近更新あり | 1（モルガン・スタンレーMUFG、0 営業日前） | **入れる** | 現在の建玉として使える唯一の値 |
| 報告義務中・報告が止まっている | 1（ExodusPoint 1.07%、**1,423 営業日前**） | 入れない | 0.1% 動くたびに報告する義務があるので、5.6 年更新が無い値は現在の建玉の証拠にならない |
| 閾値割れ | 17（0.34%〜0.49%） | 入れない | 実際の建玉は「その値以下のどこか」で不明 |
| 解消 | 5（明示的にゼロ） | 入れない | ゼロと報告済み |

**なぜ「跌破门槛」をゼロと書かないか**: 0.5% を割ると最終報告を 1 本出して
報告義務が消える。以降の建玉はゼロかもしれないし 0.49% のままかもしれない。
ゼロと書けば売り方を数え損ない、最終値を合計に足せばいない売り方を数える。
どちらも間違いなので、`exact_position_known = False` として **数えるが足さない**。

## 3. 価格の側で何が起きたか

| 指標 | 値 |
| --- | --- |
| 終値 | 2,200 |
| 52 週高値からの下落 | −64.17% |
| 252 日の価格分位 | 0.54 |
| 相対 TOPIX（20 日） | **−27.81%** |
| 相対 東証33業種（20 日） | **−31.77%** |
| 20 日の公開空頭圧力 | +0.036 ADV20 |
| 公開可見回補天数 | 0.21 日 |

価格は 6/26 の 4,180 から 8/3 の 2,200 まで下げている。この期間に分割・併合は
無い（`adjustment_factor` が 400 日ぶんすべて 1.0）ので、調整漏れによる
見かけの暴落ではない。

52 週下落が −64% なのに価格分位が 0.54 なのは矛盾ではない ——
52 週高値が一時的なスパイクで、その後の大半の日はもっと低い水準にある。

## 4. なぜ「背离失效」になったか

状態の定義は「空頭が増え続け、価格が長期支持を割り、相対も悪化」。3 つとも
満たしている:

* 公開空頭は 20 日で +0.036 ADV20（増加側）
* 200 日線を 3% 以上下回る
* 相対 TOPIX −27.81% / 相対業種 −31.77%（いずれも背離失効の閾値 −5% を大きく下回る）

補助ラベル: `below_threshold` `concentrated` `multi_reduction` `reentry`
`regulated` `rotation` `single_institution`。

**「機関が再参入している」ことは事実だが、それは利好の証拠ではない。**
過去 20 営業日で 3 社が再参入し 9 社が減らし 2 社が閾値を割った。入れ替わりは
起きているが、価格はその間ずっと市場に対して負けている。指令書 §一が
禁じている「空头减少意味着股票必涨」「机构重新做空意味着必然挤空」の類の
推論はしていない。

## 5. なぜデータ信頼度が 0.40 なのか

| 減点理由 | 効果 |
| --- | --- |
| 可視機関が 1 社だけ | ×0.8 |
| 機関名の対応づけに不確実なものがある（Citigroup / UBS / Credit Suisse / Morgan Stanley 系で正規化統合が起きている、信頼度 0.75） | ×0.75 |
| 信用規制あり | ラベルのみ |

信頼度は `monitor_priority`（並べ替え）にも状態判定にも効くので、この銘柄は
ランキング上位には出てこない（`monitor_priority` 11.66）。

## 6. 明示的にやっていないこと

* 「機関が仕込んでいる」「意図的に売り崩している」といった意図の推定
* 「閾値割れ 17 社は実質ゼロ」という仮定（未知として扱う）
* 「再参入したから踏み上げ候補」という飛躍
* 3905 を有利に見せるためのパラメータ調整

## 7. 指令書 §十五 との対応

> 目标不是强制把3905判定为利好。（…）也可能因为真实数据、日期或价格表现不同，
> 得到：正常做空 / 背离失效 / 数据不足。**必须以真实J-Quants数据为准。**

実データが与えた答えは **背离失效**。指令書が例示した「低位冲突 + 机构轮换 +
机构重新进入」ではない。輪換と再参入はラベルとして立っているが、価格が
20 日で市場に 27.8% 負けている以上、主要状態は背離失効になる。
