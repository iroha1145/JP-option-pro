# 日本站界面对齐美国站与清理记录（2026-11-21）

本次以美国站 `c957700c`（2026-11-13）为参考，在日本站 `ff01356` 基础上修改，分支 `claude/us-align-2026-11-21`。上一轮对齐的参考版本是 `a6339af`（2026-10-20），本轮搬的是这两个版本之间美国站的界面改动。本记录只描述合并前的本地修改与验证，不含线上发布。

## 搬了什么

- **版式**：全部 13 个页面改用同一套页面堆叠、12 栏网格与面板；卡片圆角 24 像素并带静止阴影；字号改用 rem 字阶，正文 16 像素；登录页改成两栏布局；404 页改成居中卡片。具体类名与取值见 `UI_DESIGN_SYSTEM.md` 的「版式与表面」。
- **财报日历**：周历与月历改用同一份样式（`components/earnings/calendar.css`），加载骨架沿用真实日历的外壳，数据到达时页面不跳动。三态（已公布、已确认、预估）与会计期间标注保留。
- **细节**：去掉侧边彩条；菜单条目的圆角比外框小一档；通知带状态图标；长说明限制在可视范围内并可滚动；手机上的小控件撑到 44 像素；分段控件切换后保持焦点项可见。
- **手势**：开关与手机「更多」面板换成美国站现行的物理实现，面板把手可用键盘操作。
- **加载**：设置菜单与命令面板改为用到时才下载；构建目标改为当前的现代浏览器；表格行不再逐行做位置动画；图表遵循系统的减少动态效果设置。入口脚本从 64.4 KB 降到约 62 KB，样式表从 130 KB 降到约 115 KB（均为压缩前）。

## 没搬的

- 美国站 11 月 13 日的文案精简和字典改写：两站文案各自维护。
- 美国站专属模块：趋势资金（CTA）、新闻催化、宏观环境、市场报告、信号读数换算。
- 美国站的构建期检查插件（应用外壳校验、启动资源清单）：日本站的构建配置与它差别很大，且本站有逐字节的产物闸门。

## 按现代网页指南做的修改

对照 Chrome 团队的 Modern Web Guidance（`modern-web-guidance` 1.0.1，读了 44 份指南）检查后修改：

| 问题 | 修改 |
| --- | --- |
| 深色用户在主脚本执行前先看到浅色页面；日文用户首屏的 `lang` 是 `zh-CN` | 新增 `public/theme-boot.js`，在首次绘制前设置外观与语言 |
| 图标用相对路径，在 `/stock/7203` 这类地址下取不到 | 改成绝对路径 |
| 16 处聚焦环是半透明品牌色，浅色底上对比度约 1.5:1，低于 3:1 | 统一成实色；另有 3 处去掉了默认轮廓却没有替代指示，已补上 |
| 选股结果表的行被标成按钮，读屏软件读不出行列对应 | 行恢复表格语义，行尾改成真正的展开按钮 |
| 系统要求更高对比度时滚动条仍然很淡 | 增加高对比度下的滚动条配色 |
| 首页近期财报列表有重复键告警 | 键里加上行号 |

核对后没改的：ES2023 的数组新方法（项目的编译目标是 ES2022）；页面不进入后退缓存（登出后按后退不该看到上一个账号的画面）；自写浮层换成原生对话框（改动大、支持有限）；分段控件的标签页语义（影响十几处与测试）。`DataTable` 的可点击行仍带按钮角色：突破雷达列表靠它用键盘选中事件，要改需要先给这一行加一个真正的按钮，留待单独处理。

网页字体栈没有日文字体，日文界面的汉字会落到简体中文字体上。这不在指南范围内，本轮没有改，需要另行决定。

## 清掉的美国站残留

- 无人引用的组件：`InsightLineChart`、`AnalysisIcon`、`PulseDot`、`InlineFallback`。
- 手动画线工具的遗留：18 个图标及其动作、画线对象的类型与几何函数。本站只有自动画线。
- 财报盘前、盘后、待定时段的配色变量与样式类。
- 带美国站含义的图标名：`clock-ny`、`sun-bmo`、`moon-amc` 改为 `clock`、`sun`、`moon`。
- 约 70 条无人引用的样式规则（模型分析按钮、新闻状态栏、数据覆盖条、多选芯片、加载转圈等）和 26 组不再使用的动画关键帧。
- 只为美国站图表服务的导出：点阵面积、斜纹柱、`upColor`、`SkeletonText`、`overlayDataOpen`、`scrollLeftToCenterChild`。
- 注释里的美股概念（期权隐含波动率排名、趋势资金、美股代码举例）改成只描述本站现状。
- 持续集成的美股残留闸门扩大到 `lib`、`hooks`、`styles` 与样式文件，并增加了美股代码与上述图标名。

有意保留的：与美国站共用账号的代码和文案；Yahoo 延迟报价（取日股与日经指数）；红涨绿跌可切换的颜色偏好；记录移植来源的文档与注释；后端三个已退役密钥的防误用检查；`snapshot_read_cache.py` 与 `http_read_cache.py`（通用底座，`migration-decisions.md` 记录为有意移植，目前没有调用方）。

## 验证

- 类型检查、静态检查、正式构建通过；`frontend/` 与 `frontend-src/dist/` 一致，用 Node 22 重建的产物也逐字节相同。
- 前端回归测试 18 组全部通过，其中新增 5 组：版式约定、启动脚本、开关物理、面板物理、手机长说明。
- 后端测试 730 项通过。另有 3 项在本机未通过（`test_intraday_refresh` 的 tick 用例、`test_relaxed_access` 的两个用例），在未改动的 `main` 上同样复现，与本次改动无关；本轮后端只改了两处注释。
- 浏览器，本机预览、接口代理到线上只读数据：1440、390、320 像素下逐页检查 13 个页面，中、日、英三种语言都没有横向溢出和报错；深色外观与日文界面各抽查一遍。首页的主区留白、区块间距、标题字号、卡片圆角与阴影的计算值与美国站预览逐项相同。
- 浏览器，本机后端加示例数据、直接使用已提交的 `frontend/`：就绪检查通过，启动脚本在内容安全策略下正常加载；所有者身份下检查了加入关注、关注页的统计卡、卡片与表格视图。
- 操作核对：设置菜单与命令面板按需加载后可用；选股表的整行点击与行尾按钮都能展开；财报日历的翻周、点选日期、切换月历可用；手机「更多」面板可用把手按钮与方向键收起。

内嵌浏览器不播放动画，手势与过渡的手感只由物理测试覆盖，没有在真机上验证。没有访问生产数据库，没有部署。

选股页的侧栏改为 1536 像素以上才与结果并排（与美国站一致），1440 像素宽度下侧栏排在结果下方。
