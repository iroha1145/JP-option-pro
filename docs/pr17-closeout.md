## 部署验收追加：区分无成交与坏数据

2026-09-08 的部署验收发现，股票池 3,712 只均有当日日线，其中 35 只的价格、成交量和成交额共 11 个字段全部为空。旧分类把这些行清洗后的日期回退视为坏数据，阻止了当日发布。[J-Quants V2 日线说明](https://jpx-jquants.com/ja/spec/eq-bars-daily)明确规定，无成交日的四本值、成交量和成交额记录为空值。生产数据库样本及单只股票的原始接口返回均符合这个格式。

追加修复只把目标日唯一一行、11 个字段齐全且全部显式为空的数据记为 `excluded / no_trades`，保留排除数量和原因；不将其称为停牌，也不填入零值或前日价格。原始接口缺字段或非法数值不能经映射变成“明确无成交”。缺目标日、仅缺收盘价、有成交量或成交额却缺价格等情况仍会阻止发布；短历史也先校验目标日价格，合法短历史才按历史不足排除。全体股票均无成交时继续保留旧发布，不能清空榜单。

追加验证共 162 项定向测试通过，其中新增 52 项覆盖字段边界及真实同步、数据库、工作任务和发布流程；未重跑完整后端套件。另使用保存的 3 条生产数据库样本和 1 条原始供应商记录执行实际映射与分类，均得到 `excluded / no_trades`。这些结果验证修复代码与已取得的字段证据，尚不代表追加修复已在生产发布。
