# 日本站前后端升级说明

本次以美国站现有界面为基准，复用其已合并的通用样式和组件。日本站基线为 `a449ddb9ee89785eae22ea4c28174903c89d331c`；核对的美国站最新主线为 `f8bd6821332a427c5a183621eda5469dcd892292`。美国站未合并的保留期调整未移植。日本站原有夜间模式、排序草稿没有被合并或覆盖。

## 界面与功能

| 原有问题 | 本次调整 |
| --- | --- |
| 两站字体、颜色、控件与页头不同 | 共用美站的灰色表面、字阶、胶囊控件、圆角和深浅主题；保留日本站品牌 |
| 一级菜单八项、设置分散 | 一级导航合为六项；选股包含筛选和雷达，市场包含日股概况和机构空卖；语言、外观与涨跌颜色集中设置 |
| 首页重复卡片较多 | 指数在桌面上合成一条指标带，信号和关注动态采用列表；手机优先显示信号 |
| 新闻夹杂模型状态和后台队列 | 默认阅读原文、来源与关联股票，采集统计放到数据源栏目；失败、旧数据和空结果分开显示 |
| 320 像素下设置菜单越界、日语底栏拥挤 | 菜单在手机视口内定位，限制高度；底栏使用短标签并修复自定义字号被颜色类覆盖的问题 |
| 深色图表局部仍按浅色绘制 | 图表、自动画线、标注和提示随主题更新；保留缩放状态；热力图文字按底色保证对比度 |
| 登录切换后可能残留旧账户页面 | 确认凭证变更后先失效旧身份与缓存；页面按明确的角色和账号重新建立 |

日本交易时段、日线日期、证券代码、红涨绿跌偏好、机构空卖、历史验证和数据状态保留。自动画线和空卖规则分类是确定性计算，继续保留。

界面以清楚的名称、可见的当前页、主次操作与真实状态降低理解成本；用对比、重复、对齐和内容分组统一信息层次。这些原则分别参考 [Steve Krug 的《Don’t Make Me Think》](https://sensible.com/downloads/dmmt-toc.pdf)和[《写给大家看的设计书》出版方说明](https://www.pearson.com/en-us/subject-catalog/p/Non-Designer-s-Design-Book-The-4th-Edition/P200000000691?view=educator)。视觉和代码基准是美国站，不另建第三套风格。

## 后端与历史数据

- 删除模型客户端、新闻翻译与分析任务、入队逻辑、任务注册、模型密钥声明及依赖。旧 `scheduled` 新闻配置转为原文同步，旧模型配置被忽略。
- 新闻接口不再返回模型翻译、分析正文、模型队列或配置状态；前端类型同步收紧。
- 历史新闻字段和旧作业数据库保留，旧作业数据库继续纳入备份，但不再打开执行。没有删除生产数据。
- 健康检查只统计当前注册任务，旧模型失败行不再使服务误报异常。
- 就绪检查核对页面直接资源及容器构建清单；资源缺失返回未就绪。经济日历拒绝无效日期和反向区间。

分包前后使用同一份源码比较：首页初始资源从 16 个减到 8 个，脚本与样式压缩后总量约从 255.70 千字节减到 253.30 千字节；主要收益是减少请求和独立缓存。首页在改动前后都不提前加载重型图表。按需图表文件仍超过构建工具的默认提示阈值，提示没有被隐藏。

## 验收边界

本地预览使用合成测试数据，不能作为真实行情或生产数据健康证明。本轮没有迁移或删除线上数据库，没有合并、部署，也没有运行真实供应商请求。发布前仍需独立完成生产备份、版本核对、真实数据和两个站点的上线检查。唯一已观察到的后端测试提示是现有测试客户端的弃用警告。

本机截图、接口响应和测试日志保存在被版本控制忽略的 `output/`；可通过本地预览 `http://127.0.0.1:2512/` 查看改版。
