# 日本站界面与动效约定

日本站沿用美国站已合并的界面基础，参考版本为 `a6339af032163a1ad4554d523831cbf0b670308c`。移植仅涉及界面行为；日本页面、日线说明、东京交易时段、日中英文字与默认红涨绿跌仍由日本站原有实现负责。

## 页面与导航

页面直接出现在最终位置，不再给整页添加入场位移；路由与身份变化仍重建页面状态。主内容区至少一屏高，底部留白跟随手机导航实高，避免长翻译和放大文字时遮住页尾。

桌面导航保留日本站入口与分组，下划线跟随当前页；鼠标在各项间移动时，浅底随之滑动。手机顶栏与底栏共用玻璃样式，支持模糊时使用半透明背景；系统要求减少透明度时恢复实色背景。

## 开关和更多面板

`Switch` 支持普通点击、键盘与水平拖拽。拖拽保留纵向页面滚动，越界时有弹性阻力，松手按位置与当前速度判定切换；取消、失焦和禁用会结束当前手势。手势产生的点击不会让开关重复切换。

手机「更多」保留财报日历、新闻、数据状态和历史验证。顶部把手可向下拖动关闭，距离不足时回弹，入场和回弹途中都能重新抓取。面板只由一处控制位移，避免样式与动画库争抢同一属性。关闭、取消或失焦时清理捕获与动画。减少动态效果偏好关闭自动过渡，拖动仍按用户手指的位置跟随。

数学与手势实现在 `src/lib/feel.ts`，参考 Feel 的质量、频率、阻尼参数、橡胶阻力、动量投射及弹簧动画交接。回弹使用内部弹簧模拟（RK4），仅保留当前开关与面板所需的固定参数；不包含通用词语编辑、磁力井、解析曲线生成和演示接口。未增加运行时依赖。

## 主题切换

页头设置与登录页外观控件从触发按钮中心向外扩散新主题。菜单先关闭并归还焦点，再捕获主题画面，避免把菜单留在快照中。快速连续选择只允许最新选择生效，结束后清理扩散变量；系统跟随、`optixjp_theme` 存储与颜色偏好互不混用。

浏览器不支持视图过渡（View Transition）、启用减少动态效果或新旧实际外观相同时，立即应用偏好。系统变化与其他标签页同步继续使用原有主题监听。

## 图标反馈

`Icon` 默认静态。操作图标添加 `motion`，外层按钮或链接添加 `icon-motion-trigger`；选中反馈可使用 `motionActive`。现有美国站 54 种图标动作按原实现移植，日本额外的列表与卡片图标保留静态图形。

图标仅在悬停、可见键盘焦点、按压或选中时响应一次，周期为 800–1000 毫秒；重复事件不中断正在进行的动作。禁用控件和减少动态效果偏好下保持静态。只改变图标内部部件，控件尺寸与布局保持稳定，数据图标不自动循环。刷新箭头的局部动作与按钮实际忙碌状态分开处理。

图标拆分与错峰反馈参考 Lucide Animated，继续使用项目自绘路径。来源版本与许可见根目录 `THIRD_PARTY_NOTICES.md`。
